# 우리 강아지를 소개합니다

사진과 정보를 넣어 입양·임시 보호 홍보 영상을 만드는 모바일 웹앱(PWA)입니다. 별도 앱 설치 없이 Safari(iPhone)와 Chrome(Android)에서 열 수 있고, 지원되는 휴대폰에서는 홈 화면에 추가해 앱처럼 실행할 수 있습니다.

## 휴대폰에서 사용하기

앱 주소: https://abc999o.github.io/pet-promo-video/

컴퓨터나 휴대폰의 Safari 또는 Chrome에서 주소를 열면 됩니다. iPhone은 Safari 공유 메뉴에서, Galaxy는 Chrome 메뉴에서 홈 화면에 추가할 수 있습니다.

- iPhone: Safari에서 주소를 열고 공유 메뉴 → 홈 화면에 추가
- Galaxy: Chrome에서 주소를 열고 메뉴 → 앱 설치 또는 홈 화면에 추가
- 사진·영상은 브라우저 안에서 처리되며 서버로 전송되지 않습니다.
- 영상 제작은 수 초에서 최대 3분까지 걸릴 수 있습니다. 제작 중 브라우저를 닫지 마세요.
- 저장 버튼은 기기의 공유 메뉴를 열어 사진 앱/파일 앱 저장을 지원하고, 아래 파일 저장 링크도 제공합니다.

## 들어 있는 기능

- 입양 홍보와 임시 보호 홍보 흐름
- 세로·가로 영상, 사진과 영상 혼합 업로드(최대 20개)
- 이름, 품종, 나이, 성별, 체중, 중성화, 지역, 보호 기간, 비고, 문의 정보
- 포스터 문구, 공통 글꼴, 색상, 첫 사진 자동 가운데 배치
- 3초 포스터 + 파일 순서대로 재생 + 5초 정보 카드, 크로스페이드
- 브라우저가 지원하는 MP4 또는 WebM 형식으로 저장

## 지원 범위

휴대폰 브라우저의 내장 녹화 기능을 사용합니다. MP4/WebM 인코더와 HEIC 사진 지원 여부는 iOS·Android 버전과 브라우저 버전에 따라 달라질 수 있습니다. 브라우저가 MP4를 지원하지 않으면 WebM으로 저장됩니다. HEIC 파일을 열 수 없다는 안내가 나오면 사진 앱에서 JPEG로 변환해 다시 선택하세요. 업로드 파일이나 생성 영상은 앱의 임시 메모리에만 존재하므로 페이지를 닫기 전에 영상을 저장하세요.
